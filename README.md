# heli

Heli is the private, lightweight, powerful CRM solution you've been looking for.

## Get started

**Hosted:** [heli.so](https://heli.so) — free for solo, no setup.

**Self-host:** SSH into any Linux VPS and run

```bash
curl -sSL https://heli.so/install | sh
```

The installer asks for your domain and an email, then handles everything
(Docker, Caddy, TLS, the container). Full guide: [SELFHOST.md](./SELFHOST.md).
